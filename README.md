# dtll.org — DTLL Group careers + menu landings

Static site for **DTLL Group**: Dough Bros, Paradise Pizzas and Nalou Kitchen.

Live: **https://dtll.org** (Cloudflare Pages project `dtll-careers`, deploys from `main`)

## Cloudflare Pages

1. Cloudflare Dashboard → Workers & Pages → Pages project `dtll-careers`
2. Repo: `LNMD2025/dtll-careers`
3. Framework preset: None
4. Build command: empty
5. Output directory: `/`
6. Custom domains: `dtll.org` and `www.dtll.org`

Do not wrangler-deploy this site. Do not create a new Pages project.
