# Extra photo drop zone

**Live pages load from `media/`.** This folder is an extra drop zone.

Dean-owned Drive stills are already in `media/` under the `doughbros-*` / `paradise-*` / `nalou-*` names. See `media/SOURCES.md`.

1. Upload extras into `media/` (preferred) or here.
2. Point the HTML `src` at the new filename.
3. Do not hotlink Drive or Instagram CDNs.
